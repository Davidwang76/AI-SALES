# 外部连接状态

| 能力 | 当前实现 | 本次实际连接 | 正式启用所需 |
|---|---|---|---|
| PostgreSQL | SQL迁移、事务、行锁、唯一约束 | 当前机器开发/测试/Compose正式空库均已运行 | 远程部署与备份策略 |
| 私有附件 | Docker卷/本地私有文件对象，授权下载 | 上传/下载API | 上线扫描、保留策略、容量监控；可替换S3 |
| 持久后台执行 | 独立Node worker、PG排队与心跳 | 已运行 | 目标机器监控 |
| 文本模型 | OpenAI兼容HTTPS JSON接口、来源校验、待审结果、过期版本保护 | 未接通，无凭据 | MODEL_API_KEY、MODEL_NAME、批准的部署区域及数据处理范围、费用定价与真实提取/草稿联调 |
| 搜索/地图/贸易数据 | 查询计划、来源导入、候选和暂停恢复 | 自动搜索未实现适配器；不编造结果 | 选定获授权提供者、数据使用条款、预算与实现联调 |
| OCR/语音/Excel/PDF解析 | 原件私有保存、人工转写/逐行录入、CSV名录导入 | OCR等未连接 | 各能力真实适配器与授权；不能把文件保存当成提取成功 |
| 多邮箱 | 邮箱身份、会话、入站原文人工登记、草稿、序列暂停 | 无邮箱API同步或自动发送 | OAuth/API或IMAP/SMTP、线程与附件映射、回调验签及测试收件人 |
| WhatsApp | 连接状态未连接，发送统一禁用 | 无 | 官方Business API资格、号码、模板/窗口政策与实现联调 |
| 线上推广 | 内容审核、人工真实发布URL登记、UTM英文留资 | 本系统表单可运行；无平台API | 选定平台官方授权与回调实现；广告扣费继续单独授权 |
| ERP/财务 | 人工订单、核销和信用记录 | 未连接ERP | 明确外部权威、映射、幂等与对账实现 |
| 腾讯云部署 | Compose、迁移、首次账号、备份恢复、IP HTTPS配置 | 未登录服务器 | 恢复受控SSH通道或由腾讯云控制台执行部署包 |

当前没有任何真实客户外发、广告扣费或付款记录。业务测试均使用虚构记录与独立数据库；测试通过不是外部服务已接通。
