# 版本状态

此部署分支提供真实数据库支持的程序、锁文件、五个增量迁移和Docker部署脚本。正式初始化为空业务数据，没有固定演示客户；测试夹具全部使用独立测试库及虚构信息。

本次已有46项领域/业务测试、3条真实Chromium端到端流程通过；类型检查、前端生产构建、Docker构建、当前机器容器健康及备份恢复演练通过。新增腾讯云Nginx兼容入口通过Shell语法、Compose和Caddy配置校验，尚未在目标服务器执行。后续修改须重新核验受影响功能。

当前可运行人工采集/留资→客户/联系人/来源→核实与任务→人工来信→询盘→严格OE匹配/采购回盘/货源选择→报价计算/审批/版本→客户确认订单/分批发货/到账核实与核销；包含样品、售后、资料审批、并发预算/信用及审计基础。

完整V2.0需求尚未全部实现或验收。真实搜索、OCR/语音/Excel-PDF解析、多邮箱同步/发送、WhatsApp和ERP等仍需实现/授权联调。复杂适配、拆供合并、税费折扣、信用例外及双人敏感审批、完整退款/退货/应收催收、知识历史版本、全量工作流和灰度回滚等仍有缺口。所有对外消息、广告投放与付款继续关闭；不把缺凭据功能称为已连接。

尚未完成10万线索容量、附件病毒扫描、跨机器灾备与全部阶段安全验收。因此不能称为全量正式上线版本，也不能将已有自动测试视为整套规格已通过。
