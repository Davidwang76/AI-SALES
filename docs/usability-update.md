# 资料收集与导航更新

根据首次使用反馈，菜单分为日常工作、获客与推广、交易与履约、团队与设置；首页只展开日常工作。可在“找功能”输入员工、收款、截图等常用说法定位功能。分组仅改善查找，不改变后端权限，也不补齐尚未实现的平台管理员体系。

首页“先收集资料”支持选择文件、手机拍照入口、粘贴截图、拖入文件、直接保存原文。原件保存在已有私有文件存储和 sources 表，按经营主体及现有权限访问。资料名称可由文件名或原文首段生成，不必先填写客户档案。文字原文与附件每次单独保存。每次一份文件，最多25MB，支持JPEG/PNG/PDF/TXT/CSV/WebM，不支持HEIC。

“采集资料箱”可查看原文、下载原件，人工核对后关联为客户线索。生成线索仍需要来源活动、公司及邮箱或电话。联系许可默认未知。图片OCR、自动提取、录音转写没有在本轮接通；手机实际调用相机取决于浏览器和系统支持。关闭采集窗口前请自行保留原文或文件；未经提交的内容不算服务器保存。

新建活动默认显示名称和类型，其他资料及已有默认值收进可展开区域。首页增加收集资料、跟进待办、查找客户三条直接入口。

本轮不新增数据库迁移，不重新初始化账号，不修改密码，不删除数据库或附件卷。Tencent网关配置保留已验证的IP无SNI访问修复。
